# Wordlists

`common-passwords.txt` is a small built-in list of very common passwords, so the
ZIP password recovery feature works out of the box. It is a short starter list,
not a large dictionary. You can point the app at any other `.txt` wordlist (one
password per line), such as the well-known `rockyou.txt`, by choosing it in the
wordlist selector.

`common-passwords.txt` is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
