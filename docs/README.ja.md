## ✨ ほかのソフトとのちがい

WinRAR や 7-Zip でやっていた毎日の作業はもちろん、それらにはないこともできます。

- 🔑 **パスワード付きが 1 つあっても全体は止まりません。** 多くの圧縮ソフトでは、鍵付きのアーカイブが 1 つあるだけでパスワード入力画面が出て、すべてが止まってしまいます。Quick Extract Ultra ではそのファイルだけ脇に置いて、ほかは展開を続けます。パスワードは都合のいいときに入力すれば OK です。
- 🔍 **アーカイブを自動で探します。** フォルダーを選ぶだけで、サブフォルダーの奥にあるものまでまとめて見つけ、一度に展開します。それぞれ専用のフォルダーに入ります。
- 🛡️ **中途半端なフォルダーは残しません。** まず一時フォルダーに展開し、7-Zip がすべて正常だと確認してから本来の場所へ移します。途中で問題が起きても、フォルダーは元のまま。上書きも一切しません。
- 🧹 **「フォルダーの中に同じフォルダー」とはお別れ。** スイッチ 1 つ（スマート）で、いらない入れ物フォルダーを省きます。
- 🔓 **自分のファイルのパスワードを忘れても、取り戻せるかもしれません。** 自分の ZIP や RAR のパスワードを忘れたときは、アプリが探してみます。可能ならグラフィックボードも使います。ほとんどの圧縮ソフトにはない機能です。
- 💸 **ほんとうに無料。** 広告も試用期間も「購入してください」のお知らせもありません。パソコンの中だけで動くので、ファイルが外に送られることもありません。
- 🌏 **見やすくて、日本語もばっちり。** すっきりしたモダンな画面を、English・日本語・简体中文・繁體中文・Tiếng Việt で使えます。

## 📥 ダウンロードとインストール

1. [**最新リリース**](https://github.com/nyankuro/quick-extract-ultra/releases/latest)のページを開きます。
2. どちらかをダウンロードします。
   - **`QuickExtractUltra-Setup-x.y.z.exe`**：インストーラーです。迷ったらこちら。スタートメニューとデスクトップにショートカットを作ります。管理者権限はいりません。
   - **`QuickExtractUltra-Portable-x.y.z-win-x64.zip`**：インストール不要のポータブル版です。好きな場所（USB メモリでも OK）に展開して `Quick Extract Ultra.exe` を実行します。
3. 起動します。青い「Windows によって PC が保護されました」が出たら、**詳細情報** →**実行** をクリックしてください（[なぜ出るの？](#安全ですか)）。

アンインストールは Windows の **設定 → アプリ** から。右クリックメニューも一緒に片付きます。

### 安全ですか？

はい、安全です。あの青い画面は、アプリが新しく、まだコード署名（毎年費用がかかります）をしていないために出るもので、ウイルスの警告では**ありません**。このバージョンを使う人が増えると、出なくなることもあります。（Ko-fi での応援は、いつか署名を取るための力になります。）

自分で確かめたいときは：
- ダウンロードできるファイルはすべて、ここで公開しているソースコードから GitHub が自動で作っています。誰かのパソコンで作ったものではありません。作成の記録は [Actions](https://github.com/nyankuro/quick-extract-ultra/actions) で見られます。
- 各[リリースページ](https://github.com/nyankuro/quick-extract-ultra/releases/latest)に、ファイルごとの SHA-256 チェックサムと、70 以上のウイルス対策ソフトで調べた VirusTotal の結果へのリンクを載せています。
- Quick Extract Ultra は、この GitHub ページからだけダウンロードしてください。ほかのサイトにあるものは改ざんされているおそれがあります。

### 30 秒で試してみる

1. アーカイブをウィンドウにドラッグするか、**ファイルを選択** をクリックします。
2. **すべて展開** をクリックします。
3. これだけ！ それぞれのアーカイブのすぐ隣に、新しいフォルダーができています。

## 📖 使い方

### 展開する

**展開** タブを開いて、アーカイブをドロップするか、次のボタンを使います。

- **ファイルを選択**：展開したいアーカイブを自分で選びます。
- **フォルダーを検索**：フォルダーの中のアーカイブをまとめて探します。
- **詳細検索**：サブフォルダーの中まで探します。

スイッチで細かく調整できます。

- **保存先**：選んだファイルの展開先です。初期設定は「各アーカイブと同じ場所」。クリックすると別のフォルダーを選べ、× で元に戻ります（フォルダー検索のときは、いつもアーカイブと同じ場所に展開します）。
- **スマート**：中身がフォルダーやファイル 1 つだけなら、余計なフォルダーで包まずにそのまま取り出します。
- **まとめフォルダー**：結果をすべて 1 つの `Main Zip` フォルダーに入れます。**新規まとめ** は今回用に `Main Zip (1)` を新しく作ります。
- **書庫を削除**（オレンジのスイッチ）：展開に成功したアーカイブを、その場で**完全に削除**します。ごみ箱には入らないので、初めてオンにするときは確認画面が出ます。展開に失敗したときやキャンセルしたときは、何も削除しません。

あとは **すべて展開** をクリックするだけ。同じ名前のフォルダーがあれば `(1)`、`(2)`… と番号を付けるので、上書きは一切しません。

パスワードが必要なアーカイブは、その行にパスワード欄が出ます。入力して **続行**、または **スキップ**。その間もほかのアーカイブは展開を続けます。

### アーカイブを作る

1. **圧縮** タブでファイルやフォルダーをドロップします（**ファイルを追加** ／ **フォルダーを追加** も使えます）。
2. 名前、保存場所、形式、圧縮率を選びます。
3. 必要なら、パスワード（7Z・ZIP）、ファイル名を隠す（7Z）、分割（100 MB・700 MB・1 GB・4 GB）も設定できます。
4. **アーカイブを作成** をクリック。できあがったら **フォルダーで表示** で確認できます。

> 💡 ZIP のパスワードに使えるのは半角英数字と記号だけです（7-Zip の制限）。日本語を含むパスワードにしたいときは 7Z を選んでください。

### 中身をのぞく

**中身を見る** タブでアーカイブをドロップします。フォルダーはダブルクリックで開き、名前で検索もできます。必要なものにチェックを入れて **選択項目を展開** すれば、全部を展開しなくても大丈夫です。

### テストとチェックサム

**テスト・チェックサム** タブでは、展開しないままアーカイブ内のファイルが壊れていないかを確認できます。どんなファイルでも CRC32・MD5・SHA-1・SHA-256・SHA-512 を計算でき、サイトに載っている値を貼り付ければすぐに照合できます。

### 右クリックメニュー

**設定 → エクスプローラーの右クリックメニュー** をオンにすると、エクスプローラーの右クリックに「ファイルを展開...（保存先を選択）」「ここに展開（スマート）」「フォルダーに展開」「ZIP に追加」「チェックサムを計算」などが加わります。Windows 11 では **その他のオプションを確認**（または Shift+F10）の中にあります。追加されるのはいまの Windows ユーザーだけで、オフにすると消えます。

### 忘れたパスワードを探す

自分の ZIP や RAR のパスワードを忘れてしまったら、**パスワード復元** タブで探せるかもしれません。

> ご自身のファイル、または開く許可のあるファイルにだけ使ってください。

- **初めて使うとき**は、無料のツール bkcrack・hashcat・John the Ripper の 3 つが必要です。アプリには入っていないので、**すべて自動でダウンロード**（それぞれの公式サイトから）か **自分で追加する** を選びます。一度だけで大丈夫です。
- **次からは**、アーカイブを選んで **自動で試す** をクリックするだけ。まず数字、次によくあるパスワードとその変化形、それから範囲を広げて探します。新しい形式の ZIP と RAR5 ではグラフィックボード（GPU）を、それ以外はプロセッサー（CPU）を使います。
- **処理レベル**：ふつうは *バランス* で OK。*省電力* はパソコンが熱くなりにくく静か、*最大* はいちばん速いぶん熱くなります。
- いつでも **一時停止**・**再開**・**キャンセル** できます。見つかったらコピーするか、**今すぐ展開** をクリックしてください。

知っておいてほしいこと：短くて単純なパスワードなら数秒で見つかることもありますが、長くてランダムなものは何日もかかったり、見つからなかったりします。古い形式の ZIP で、中に入っていた元のファイルが 1 つでも手元にあれば、それを使ってとても速く開けられます。また、ウイルス対策ソフトがこうしたツールを誤って危険と判断することがあります。ダウンロードしたツールが消えてしまったら、ウイルス対策ソフトの検疫を確認してみてください。

### 設定

| 設定 | 初期値 | 内容 |
|---|---|---|
| 言語 | English | English・日本語・简体中文・繁體中文・Tiếng Việt |
| エクスプローラーの右クリックメニュー | オフ | 上で紹介した右クリックメニューを追加します |
| 展開後にフォルダーを開く | オフ | 終わったら結果のフォルダーをエクスプローラーで開きます |
| ダウンロードの安全警告を引き継ぐ | **オン** | ダウンロードしたアーカイブから取り出したファイルにも「インターネットから取得」の印が残り、SmartScreen や Office の保護が続きます |
| 展開後にアーカイブをごみ箱へ移動 | オフ | *書庫を削除* よりやさしい方法です。あとから元に戻せます |
| 更新を確認 | | 新しいバージョンが出ているか確認し、あればダウンロードページを開きます |

## よくある質問

**RAR ファイルは作れますか？**
いいえ。RAR を作れるのは WinRAR だけです。Quick Extract Ultra は RAR（RAR5 も）を開けて、どのソフトでも開ける 7Z・ZIP・TAR を作れます。

**ファイルがどこかに送られることはありますか？**
ありません。処理はすべて、おなじみの 7-Zip エンジンでパソコンの中だけで行い、利用状況の送信などもしていません。インターネットにつながるのは、あなたが **更新を確認** を押したときと、パスワード復元用のツールをダウンロードするときだけです。

**どんな形式を開けますか？**
ZIP、ZIPX、7Z、RAR（RAR5 含む）、TAR、GZ、TGZ、BZ2、XZ、TXZ、ZST、LZ、LZMA、Z、CAB、ISO、WIM、ARJ、LZH/LHA、CPIO、RPM、DEB、DMG、VHD、VHDX、XAR。`.part1.rar` や `.7z.001` のような分割ファイルは、最初のファイルから開けます。

**設定はどこに保存されますか？**
`%APPDATA%\quick-extract-ultra\settings.json` です。アーカイブの一覧やパスワードは保存しません。

## 開発者の方へ

<details>
<summary><b>ソースからビルドする</b></summary>

[Node.js](https://nodejs.org/) 22 以上と Windows 10/11 が必要です。

```bash
git clone https://github.com/nyankuro/quick-extract-ultra.git
cd quick-extract-ultra
npm ci
npm run dev        # 開発モードで起動（自動リロード）
npm test           # アーカイブの統合テスト（本物の 7-Zip を使用）
npm run test:ui    # Electron の UI テスト
npm run dist       # インストーラーとポータブル版を dist/ に作成
```

構成：`electron/`（メインプロセス、7-Zip、エクスプローラー連携）、`src/`（React の画面）、`locales/`（翻訳）、`scripts/`（テストとツール）。

バグ報告、アイデア、翻訳はいつでも [Issues](https://github.com/nyankuro/quick-extract-ultra/issues) で歓迎しています。新しい言語を追加するには、`locales/en.json` をコピーして翻訳し、`src/i18n.tsx` と `electron/settings.cjs` に登録してください。

</details>
